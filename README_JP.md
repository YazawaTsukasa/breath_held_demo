# Breath Held Demo

2D トップダウン・アクションアドベンチャー　／　個人開発ポートフォリオ作品

---

## 概要

Godot 4 / GDScript で制作中の2Dアクションアドベンチャーゲームのデモです。  
UE5/C++ をメイン技術とするゲームエンジニアが、エンジンを問わない汎用的なシステム設計・実装能力を示す目的で開発しています。

| | |
|---|---|
| エンジン | Godot 4（GDScript） |
| ジャンル | 2D トップダウン・アクションアドベンチャー |
| 開発形態 | 個人開発（設計・実装・デバッグすべて単独担当） |
| 開発期間 | 2026年〜（継続開発中） |

メインメニュー → ゲーム開始 → テストシーン（各システムのデモプレイ） → プレイヤー死亡 → 死亡画面 → 任意キーでメインメニューへ戻る → 再プレイ or 終了、の一連のゲームループを実装済みです。

## 実装システム

| システム | 概要 |
|---|---|
| キャラクター基底クラス | Player / Enemy の共通ロジックを抽象化した基底クラス設計 |
| コンポーネントシステム | 任意の Actor にアタッチして機能を付加できるコンポーネント設計 |
| アイテムシステム | Resource ベースのデータテーブル＋ファクトリクラスによるアイテム生成管理 |
| エフェクトシステム | ヒット・状態異常等を統括する汎用エフェクト管理 |
| プレイヤー属性システム | HP・スタミナ等を一元管理する属性コンポーネント |
| HUD / UI システム | プレイヤー属性とリアルタイム連携するゲーム内HUD |
| Autoload アーキテクチャ | Global / InGame の二層に分けたシングルトン設計 |
| 戦闘システム | 近接・遠距離・投擲の三種を統合した戦闘フレームワーク |
| タイルマップ | フロア・障害物・当たり判定を含む2Dワールド環境 |
| 敵 AI ステートマシン | Idle / Chase / Attack / Dead の状態遷移を管理するFSM |

## 設計ハイライト

### コンポーネントシステム

共通の基底クラスは持たず、各コンポーネントは用途に応じた親クラスを個別に継承する柔軟な構成。機能用途によって二つのカテゴリに分類しています。

- **汎用コンポーネント**（`Components/`）：任意の Actor にアタッチ可能。属性管理・エフェクト付与・当たり判定等を機能単位で分離
- **AI専用コンポーネント**（`Components/AIComponents/`）：Sensor（プレイヤー検知）・Movement（移動制御）等。AIステートマシンと連携し、状態ごとに必要なコンポーネントのみを駆動

### アイテム・武器の継承設計

```
ItemBase
├── WeaponBase
│   ├── MeleeWeaponBase
│   └── LongRangeWeaponBase   # 弾薬の装填・発射を管理する発射器
└── PropBase
```

`LongRangeWeaponBase` が発射器として弾薬の装填・発射を担い、発射された弾丸オブジェクトの弾道制御を行う設計です。

### Autoload の二層管理

```
Global（全局機能）
├── ResourceManager   # 各種データテーブル Resource のグローバルロード・提供
└── GameManager       # シーン切り替えおよびシーン間ブロードキャスト

InGame（インゲーム機能）
├── PlayerController    # プレイヤー入力・制御
├── PlayerDataManager   # 所持アイテム・ステータス値と変化コールバック管理
├── UIManager           # ゲーム内UI全体の制御
└── SpeedManager        # ゲームスピードの一元管理
```

## プロジェクト構成

```
BreathHeld/
├── Assets/          # 画像・スタイル等のアセット
├── Content/         # シーンファイル（.tscn）
│   ├── Actors/      # キャラクター・コンポーネント・アイテム
│   ├── UI/          # UIシーン
│   └── Worlds/      # マップ・ワールドシーン
└── Source/
    ├── GDScript/    # スクリプト（.gd）
    │   ├── Actors/
    │   ├── Effect/
    │   ├── System/  # Autoload（Global / InGame）
    │   └── UI/
    └── Resource/    # データ定義（Resource / DataTable）
```

## 動作環境・実行方法

1. [Godot 4](https://godotengine.org/) をインストール
2. リポジトリをクローン
   ```bash
   git clone https://github.com/YazawaTsukasa/breath_held_demo.git
   ```
3. Godot でプロジェクトを開き、`project.godot` をインポート
4. `F5` で実行
